# AGENTS.md

## Build/Lint/Test Commands
- Build: `npm run build`
- Lint: `npm run lint`
- Test: `npm test`
- Run a single test: `npm test -- --testNamePattern=<test_name>`

## Code Style Guidelines
- Imports: Use absolute imports.
- Formatting: Follow Prettier conventions.
- Types: Use TypeScript for type annotations.
- Naming Conventions: Use camelCase for variables and functions, PascalCase for classes.
- Error Handling: Use try-catch blocks for asynchronous operations.
